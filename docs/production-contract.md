# Ailya 生产实现约束

此文件记录用户确认的行为，前端数据和浏览器计时器不能替代生产实现。

- Core 常驻；浏览器关闭后任务继续。暂不设置并发上限。生产执行由 Core 管理。
- 只有停止，没有暂停。停止阻止后续步骤，向主任务和子任务传递取消信号；已经修改的文件不回滚。无法安全取消的操作必须准确反馈停止状态。
- 重试覆盖旧回复记录；不得因此假设外部写操作已回滚。
- 总耗时包括执行、工具、等待用户及停止后到继续的时间。恢复同一任务保留最初开始时间。
- 一批问题从首次展示起共用 30 秒，不因输入、选择、切换而重置；支持单选、多选、文本及选择加补充。
- 超时停止任务，保留问题；完整提交后自动继续，不重复已完成操作。拒答停止任务，恢复普通输入框。
- 子 Agent 会话只读，由主会话统一管理。
- 定时任务每次创建独立会话；关机错过不补跑，记录错过。
- 个人微信扫码绑定；多个 IM 可同时在线，账号、凭据、授权范围各自独立。
- 输入框左侧权限：默认权限（风险操作授权，设置白名单）、所有权限（完全信任）。麦克风位于模型选择之后。
- 文件修改卡片必须由真实修改事件产生，完整路径、类型、增加/删除行数。默认两条，其余折叠。失败的修改不得显示为已完成。
- 卡片的行数不是 Shell 输出猜测值；创建/删除/重复修改、二进制文件应由 Core 返回明确的统计或不适用标记。

## 当前验收边界

浏览器前端已提供文件修改样例、问题计时和拒答/继续交互、权限选择、多 IM 独立配置及多行正则白名单。
模型输出、文件统计仍为预设数据；后台持久执行、Shell 取消、权限执行、真实 IM、调度、文件读写、Pi 插件加载必须在 Core 实装后验证。
不能将配置保存、模拟回复或接口 mock 测试作为这些后端能力的验收结果。
