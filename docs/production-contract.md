# Ailya 生产实现约束

此文件记录用户确认的行为，前端数据和浏览器计时器不能替代生产实现。

- Core 常驻；浏览器关闭后任务继续。暂不设置并发上限。生产执行由 Core 管理。
- 只有停止，没有暂停。停止阻止后续步骤，向主任务和子任务传递取消信号；已经修改的文件不回滚。无法安全取消的操作必须准确反馈停止状态。
- 重试覆盖旧回复记录；不得因此假设外部写操作已回滚。
- 总耗时包括执行、工具、等待用户及停止后到继续的时间。恢复同一任务保留最初开始时间。
- 一批问题从首次展示起共用 30 秒，不因输入、选择、切换而重置；支持单选、多选、文本及选择加补充。
- 超时停止任务，保留问题；完整提交后自动继续，不重复已完成操作。拒答停止任务，恢复普通输入框。
- 子 Agent 会话只读，由主会话统一管理。
- 定时任务每次创建独立会话；关机错过不补跑，记录错过。
- 个人微信扫码绑定；多个 IM 可同时在线，账号、凭据、授权范围各自独立。
- 输入框左侧权限：默认权限（风险操作授权，设置白名单）、所有权限（完全信任）。麦克风位于模型选择之后。
- 默认权限支持“允许这一次”和“会话内允许”。会话授权按相同工具、完整参数及操作描述匹配，跨消息和刷新保留，不跨会话；命令或参数改变重新询问，删除会话时删除授权。
- 文件修改卡片必须由真实修改事件产生，完整路径、类型、增加/删除行数。默认两条，其余折叠。失败的修改不得显示为已完成。
- 卡片的行数不是 Shell 输出猜测值；创建/删除/重复修改、二进制文件应由 Core 返回明确的统计或不适用标记。

## 当前验收边界

浏览器前端已提供文件修改样例、问题计时和拒答/继续交互、权限选择、多 IM 独立配置及多行正则白名单。
当前 Core 已接入真实模型流、SQLite 会话与附件、后台执行、停止、文本读写/精确编辑及真实差异、逐次授权和白名单，验证记录见 [阶段一](implementation/phase-1.md) 与 [阶段二](implementation/phase-2.md)。Shell、调度、MCP 见 [第三阶段](implementation/phase-3-tools.md)，Agent/Group 见 [Group 执行](implementation/group-execution.md)。问题批次、固定 30 秒超时、拒答、草稿恢复与同任务续跑已接入 Core，见 [提问与续跑](implementation/questions-resume.md)。真实 IM、运行时 Skills/Pi 插件及完整文件生命周期仍待实现；保留的原型页面不代表这些能力完成。
不能将配置保存、模拟回复或接口 mock 测试作为这些后端能力的验收结果。


## 冻结后的补充决定

- 2026-10-02：用户确认沿用现有布局和功能，视觉调整为选定的 macOS／iPhone 风格：中性灰白、清晰文字层级、柔和圆角及少量系统蓝；网页不添加模拟系统窗口边框。冻结标签和参考产物保留不变。

- 正式业务数据和向量统一持久化于 SQLite，由 Core 管理。具体存储边界、迁移及向量验收见 [存储架构](storage-architecture.md)。原型 localStorage 不能作为生产持久层。
- 选择问题可由 Agent 指定推荐项，标签紧邻选项文字；推荐不等于替用户选择或提交。

- 上下文采用后台提前压缩、发送时校验预算、原始记录保留的机制；摘要不能替代 Core 任务状态。Ailya 必须支持事实记忆、用户偏好和任务经验的持续修订与用户管理。完整规则见 [上下文与记忆](context-memory.md)。自动压缩与 `/compact` 手动压缩已接入，见 [实现与验证](implementation/context-compaction.md)；长期记忆设置管理、AI 对话内维护及跨会话检索已接入，见 [长期记忆首版](implementation/long-term-memory.md)；重复证据自动激活、后台学习与真实 embedding 验证仍待实现。
