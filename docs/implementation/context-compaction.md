# 自动与手动上下文压缩

日期：2026-10-02。基线 `63e2428`，本记录对应其后当前工作区实现；人工复核 pending，同一作者 self-review，未执行独立审查。

## 用户入口与行为

- 自动检查每次 Pi 模型调用的输入，包含工具循环；可用输入预算扣除模型输出预留及至少 1024 Token / 5% 上下文窗口的安全余量。估算占预算 60% 时后台准备，80% 时等待本轮压缩；任务完成后也检查是否提前准备下一轮。
- 输入框 `/` 面板新增 `/compact · 压缩上下文`，点击或 Enter 直接调用 Core，不发送普通消息、不新建聊天任务。手动操作提供状态与取消按钮，刷新后从 Core 恢复。正在执行或有未决问题时拒绝手动压缩，避免改变等待链路。
- 保留最近两轮用户消息及随后的工具调用/结果；只压缩更早的完整前缀，不拆开未配对工具调用。少于三轮、已经压缩且无新增可压缩前缀时明确反馈无需压缩。
- 聊天可见历史及原始 transcript 不替换。模型收到历史摘要、最近原文及 Core 当前任务/权限事实；摘要是非权威历史资料，不能更改权限、任务状态或问题截止时间。
- 超过 12000 字符的工具结果在请求投影中保留 2000 字符片段和原文引用，工具配对及错误标记保留。`ask_questions`、`read_context_history` 结果不走此缩略；用户输入不静默截断。只读 `read_context_history` 按消息编号分页取原文，每次最多 6000 字符，限制在当前会话。
- 无可压缩前缀时，能装入安全预算的请求可继续；超过预算则明确失败并保留记录，提示手动压缩、缩短输入或换模型。不存在无限重试。
- 模型旁的圆环显示上下文占用比例；悬停、点击或键盘聚焦可查看简写（例如 `198k / 1M tokens`）、完整数字和百分比。分母来自当前模型实际配置，分子由 Core 按当前压缩后上下文估算，不含未发送草稿；新会话已发送上下文为零。压缩、切换模型及任务状态变化后刷新，执行期间每 2 秒读取一次。读取失败显示暂不可用，不伪装成 0%。

## 数据与接口

SQLite v8 新增 `context_summaries`、`context_segments`、`context_jobs`、`context_requests`，保存摘要、按源哈希复用的分段/合并缓存、压缩状态和摘要模型请求/响应。升级前按既有机制备份；旧库业务实体和 transcript 保留，删除会话级联删除这些派生数据。

摘要绑定 session、非 system 历史截止序号、原文哈希和模型预算配置。提交时重新验证前缀；新增消息不会使稳定前缀失效，重试或修改来源使旧结果不可用。事务提交摘要与任务完成状态。切换模型/预算重新匹配，旧模型摘要不会直接套用到新配置。

每次聊天模型请求记录摘要 ID、使用范围、预算估计和策略版本。摘要使用独立调用记录，不占用执行任务的工具序号。摘要 Token 用量计入设置中的用量统计；凭据不会写入请求审计。

API：

- `POST /api/sessions/:id/compact`，严格空 JSON，返回当前状态，HTTP 202。
- `POST /api/sessions/:id/compact/cancel`，严格空 JSON，取消压缩任务。
- `GET /api/sessions/:id/context-usage?model=...`，校验模型选择，返回占用估算、模型容量、安全输入预算和生效摘要 ID，不修改会话。
- 状态随既有 SQLite 事件、WebSocket 及 snapshot 中的 `session.compaction` 同步。
- `stop` 同时取消本会话压缩；删除、Core 关闭均取消后台任务。重启把未完成压缩标为取消，保留先前有效摘要，不自动重放模型调用。

## 实现限制

- 计数采用带协议余量的保守字节估算，不宣称精确 tokenizer；按模型返回的 input/cache 用量向更保守方向校准，并持久化系数。未知模型容量沿用可配置的兼容模型容量。
- 摘要沿用当前会话的厂商/模型，因此远程模型会接收待压缩历史；没有引入其他模型厂商。摘要请求禁用工具，输出严格 JSON，校验失败不采用。
- 初始阈值 60% / 80% 是代码策略，尚无设置页面。分块大小按当前模型窗口及校准系数计算；已验证的分段与合并结果按源哈希、模型和摘要策略复用。单任务 120 秒、最多 8 次摘要请求，输出上限不超过 3072 Token；超出范围会明确失败，手动重试可复用已完成分段，不自动无限重试。近期不可压缩输入或摘要请求仍超预算时需减少输入或切换模型。
- 原文/请求审计持续留存于 SQLite，本轮未实现数据库历史归档、长期记忆、偏好学习或 embedding 检索。单次真实场景验证不能保证所有模型的摘要质量；重要细节仍应回查来源。
