## 已实现

- 默认权限下 write/edit 在 Core 等待单次允许；允许只放行当前调用，拒绝停止任务。停止取消待授权，重启将遗留请求作废；刷新恢复同一请求。授权等待不套用产品问题问答的 30 秒规则。
- 白名单及授权审计存 SQLite。每行正则匹配规范化的 `write C:/absolute/path` 或 `edit C:/absolute/path`，匹配目标路径而非文件内容；正则在独立 worker 中限时执行，超时不自动授权。
- 附件字节、哈希及会话/消息归属存 SQLite；发送事务失败不留下半份数据。工具 read_attachment 仅读取本会话附件，支持 UTF-8 文本分段；图片、音视频及 PDF 等解析未实现，不伪装成模型已理解。
- 每个附件最多 8 MiB，每次最多 10 个、合计 16 MiB。上传失败保留草稿及附件；成功后可刷新下载。删除会话级联删除附件与授权记录。
- 复用 Pi read/write/edit，限制工作空间及符号链接，精确编辑产生实际差异。无变化写入不生成修改记录；尚不覆盖删除、重命名和二进制差异。
- 0002 版本化迁移保留 v1 数据，升级前自动备份。实际运行数据库已升级至 v2；原有用户会话保留。
