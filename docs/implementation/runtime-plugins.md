# 运行时插件首版

日期：2026-10-02。基于 `74b59af` 后的工作区实现。复用「扩展 → 插件」页面，不修改冻结基线或开发 Skills。

## 安装与执行

- 支持 `npm:包名@版本`、`git:github.com/用户/仓库@引用`（也可显式 HTTP/HTTPS 地址）、本地文件或目录。npm/Git 使用已安装 Pi `0.87.1` 的 `DefaultPackageManager.resolveExtensionSources`，在 Core 的临时目录安装，依赖主机已有 npm/Git。来源不接受内嵌凭据、Shell 片段或路径穿越。
- 页面接入安装、编辑后重新安装、更新、重新加载、启停、卸载及失败状态。关闭页面不停止已提交的安装任务；Core 重启将未完成安装标为中断，不自动重放安装脚本。更新失败保留原可用版本。
- 「重新加载」检查 SQLite 中保存的包，无需原始目录或联网；「更新」重新解析来源，固定版本或 Git 引用仍保持固定。启用表示已就绪，实际会话调用时才启动执行进程。
- 包需要注册 Pi 工具，可通过 `package.json` 的 `pi.extensions` 声明入口，或使用 `index.ts` / `index.js`。首版使用当前固定版本的 Pi loader 加载显式入口，不扫描默认扩展目录。loader 为内部接口，升级 Pi 时必须重新验证。
- 内置 Ailya 可发现全部已启用插件；自定义 Agent 在 Tools 选择「插件」后可用，Group 成员遵循各自配置。模型通过 `plugin_list_tools` 查看真实工具定义，再用 `plugin_call_tool` 执行；未选择插件的 Agent 不获得网关。

## 主机执行与生命周期

安装和检查可能执行包脚本及初始化代码，界面要求信任来源。插件属于可信主机代码，能够访问工作空间外的文件、网络及主机程序；独立进程不是文件系统沙箱。子进程不继承 Core 模型密钥环境变量，也没有 Core 数据库对象，但这不能阻止可信主机代码直接访问磁盘。

默认权限下，会话调用先走既有授权，再启动插件进程并加载代码。会话授权绑定工具、完整参数、包版本和哈希；更新后的版本不会继承旧版本授权。「所有权限」跳过逐次授权。加载与调用前再次检查启用状态，等待授权期间停用或卸载会阻止执行。单纯查看工具列表不执行包代码。

安装进程的工作目录为私有临时目录；工具进程默认目录与 `ctx.cwd` 都是实际会话工作空间。每个任务固定包版本，同一任务内复用进程；新任务使用新版本。工具调用前后扫描真实工作空间差异，沿用既有大文件、忽略目录和扫描上限，不声称覆盖工作空间外的修改。

停止或超时会结束 Windows 下所拥有的进程树，任务结束会清理进程和临时副本；已经发生的文件写入、网络请求不回滚。停用/卸载阻止后续调用，不中断已经获准执行的那次调用；需要立即中断时使用会话停止。安装准备限时 180 秒，加载检查 30 秒，单次工具执行 60 秒。故意脱离进程树的后台服务、插件自行终止父进程后遗留的外部进程，以及跨平台进程组取消不在本次保证范围内。

## 持久化与升级

SQLite v11 增加 `plugins`、`plugin_versions`、`plugin_files`、`task_plugins`、`plugin_jobs`。当前配置、安装状态、版本、工具定义、原始包和依赖字节统一保存于 Core；磁盘安装目录只作为临时执行副本。升级前创建可读备份，不清空旧数据。

原型 localStorage 配置只做一次导入，保留来源且默认停用、未安装，不因迁移自动执行旧来源。备份包含插件和任务引用；恢复后可从库内包字节重新执行，不依赖原始目录。系统 Bun/npm/Git、原生依赖所需运行库及跨机凭据不随备份打包。

卸载删除当前配置并回收无引用包；被历史任务引用的版本保留用于审计；插件仍启用时，等待回答的原任务可用固定版本续跑。删除相应会话后回收不再引用的版本和文件，不删除用户原始插件目录，不撤销已执行操作。崩溃留下的磁盘临时目录尚无自动保留/清理策略。

单包限制 10,000 文件、100 MB、30 层目录和 50 个入口，拒绝包内符号链接/目录联接；忽略 `.git`、`.bin`、`.cache`。最多 100 个工具，工具元数据不超过 128,000 字符，工具结果不超过 512,000 字符。需依赖链接、`.bin` 或安装后机器绝对路径的包可能不兼容。
