# 真实提问与同任务续跑

2026-10-02。基于现有未提交工作区实现；冻结标签 `prototype-v1.0.0` / `292f432` 未改变，未提交或发布。

## 已实现

- Pi `ask_questions` 是所有 Agent 的基础交互工具，沿用现有问题面板。支持单选、多选、文本、选择加补充、推荐项；推荐不自动选择。每批最多 8 题，统一校验后提交。
- SQLite v6 新增 `question_batches`，关联主会话、实际执行会话、task 和 tool call，保存问题、状态、创建时间、固定截止时间、已保存草稿及最终回答。升级前自动备份；不迁移旧原型的模拟问题历史，不删除旧浏览器数据。
- 截止时间是 Core 首次发布批次时加 30 秒。浏览器只显示剩余时间；输入、换题、切换会话、刷新、断线和晚连接均不重置截止时间。Core 在超时边界取消执行，已完成文件操作保留。问题仍可完整回答。
- 正常回答解除工具等待；超时或重启后的回答使用持久化 transcript，并调用已安装 Pi 0.87.1 的 `Agent.continue()`。沿用原 task ID、回复 ID、开始时间、模型执行配置及该任务权限，耗时包括等待和停止间隔。不重新发送原用户指令或重新执行已完成的工具调用。
- 被取消的同批后续工具若尚未执行，会作为未执行结果交给模型重新判断；不会当作成功，也不会直接执行缺少用户回答时的旧计划。
- 拒答和主动停止使当前问题失效，恢复普通输入框；迟到回答被拒绝。完整回答幂等，重复提交旧批次不能跳过新的问题。
- Group 成员问题投影到主会话。主会话统一回答、授权、显示进度和停止；超时后先继续原子任务，再将结果交回原协调者任务。主子任务各自开始时间和 ID 保持，子会话仍只读。
- Core 重启不自动执行工具。未回答问题保留为中断或超时状态，用户提交后续跑。已保存草稿可从数据库恢复，保存/提交失败显示错误，不伪造回答成功。

接口均经 Zod 校验：`POST /api/sessions/:id/questions/:questionId/{draft,answer,refuse}`。草稿 revision 检出多窗口过期写入；回答由 Core 验证题目归属、选项、完整性及批次状态。问题答案作为对应工具结果进入模型上下文与审计。

| R-05 | 成员续跑时主会话也需展示执行中并允许停止；已同步父任务状态和取消 | 主会话停止后主子任务停止且无后续写入 |

浏览器验证首轮失败来自测试模型服务器错误绑定 Bun `fetch` 的 `this`，修复 fixture 后通过；未扩大等待时间或降低断言。

续跑保证不由执行器重放已经完成的调用；模型随后主动发起的新调用仍按工具权限执行。此能力不是通用任意位置任务恢复，也不是外部操作的回滚或全局 exactly-once 保证。模型/厂商配置被删除或地址改变时准确报错，不偷偷更换厂商或重新发送原任务。运行时 Skills、长期记忆、IM、语音、发布打包和完整 CI 不在本次完成范围。
