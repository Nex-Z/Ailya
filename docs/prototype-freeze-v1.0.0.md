# Ailya 原型冻结版 v1.0.0

冻结日期：2026-09-28（Asia/Hong_Kong）。Git 标签：`prototype-v1.0.0`。

本版本是视觉、交互和功能范围的验收参考，不是生产系统。正式版沿用现有界面组件，替换模拟运行时；所有可见能力都必须实装。修改已确认的产品行为应先与用户确认。

## 运行与验证

Node.js 环境中运行 `npm ci`、`npm run dev`。构建：`npm run build`；静态检查：`npm run lint`。启动 localhost:5173 后运行 `npx playwright test`（首次需安装 Playwright Chromium）。

冻结源码和静态产物放在 `releases/prototype-v1.0.0/`。静态包解压后使用任意 HTTP 静态服务器访问，不直接双击 index.html。推荐用独立浏览器配置查看参考版，避免与开发版 localStorage 混用。

## 已确认的交互验收清单

- [ ] Web-first，本地优先；默认 Local，Workspace 为目录。首条消息后运行上下文固定。
- [ ] 左侧会话及 Agent、Group、扩展、定时任务入口；默认不显示右侧面板。
- [ ] Agent/Group 宫格管理，新增/编辑/详情弹窗；详情可新建会话；Skills/Tools 下拉多选。
- [ ] `/` 为输入区附近的分区命令列表；上下文独立下拉；首条消息后隐藏上下文栏。
- [ ] 模型、麦克风、发送位于输入框右下；左侧附件和权限；生成时发送变停止。
- [ ] 拖入文件展示在输入框上方，待发附件按会话保留；刷新不恢复本地 File 对象。
- [ ] 运行中文字展开，工具组默认折叠且只露出最新调用；结束后全过程折叠并显示总耗时，保留最终答复。
- [ ] 每条 AI 回复耗时与正文起始对齐；失败醒目；重试覆盖旧回复及旧结果。
- [ ] 成员任务可点击打开右侧只读子 Agent 会话/状态面板，可关闭；主会话统一管理。
- [ ] 问题替代输入区，一次展示一个，左右切换，最后统一提交；每行一个选项，有 ABC 编号和明显选中状态。
- [ ] Agent 可通过 recommendedOptions 指定推荐项；标签紧邻选项文字，推荐不代表默认选择。
- [ ] 问题批次共用首次显示起 30 秒，不重置；超时停止但允许继续回答，提交自动继续；拒答停止并回到普通输入框。
- [ ] 停止无回滚；同一任务耗时包含执行、工具、等待及停止至继续时间；新任务独立计时。
- [ ] 文件卡片完整路径、绿色增加/红色删除行数，不展示新增/修改类型标签；默认两条，其余折叠。
- [ ] 点击文件看差异，支持分区行号、重命名、二进制和截断状态。
- [ ] 大尺寸分级设置；厂商增删改、动态拉取及选择模型，同名模型区分厂商；DeepSeek/OpenAI 兼容接口。
- [ ] 风险权限及多行正则白名单、Token 统计、Core、独立多 IM 配置；个人微信扫码绑定。
- [ ] 定时任务支持手动和对话创建，每次执行产生会话，离线错过不补跑。
- [ ] MCP、Skills、Pi 扩展管理；不设置并发上限，关闭浏览器后 Core 继续执行。
- [ ] 中性配色、统一 Tailwind/shadcn 组件；未经要求不加描述性小字。

上述复选框用于正式版真实验收，不表示原型已实现后端能力。详细执行规则见 production-contract.md。

## 实装边界与交接

现有 React/TypeScript/Vite、Tailwind、shadcn 源码组件、assistant-ui、Zustand 可继续使用。当前模拟回复、示例工具事件、浏览器计时器、localStorage 配置不能充当生产实现。Bun/TypeScript + Pi、Hono、WebSocket、Zod、SQLite/Drizzle 为计划中的 Core 技术方向，尚未接入。

正式版必须验证：真实模型流式输出、任务与子任务取消/恢复、权限匹配与授权、实际文件访问及差异、原生目录完整路径、真实调度和运行记录、Pi 插件加载、IM 多账号在线及微信绑定、语音输入、真实 Token 统计。厂商列表拉取受浏览器 CORS 限制，生产应由 Core 代理；凭据需安全存储。语言设置等配置必须落实到使用行为，不能只保存值。

附件当前在内存中保留文件字节，未上传给 Core；问题后继续仍为模拟回复，不代表恢复真实执行检查点。历史样例迁移逻辑不可直接作为生产会话迁移策略。

## 后续开发规则

冻结标签不移动、不覆盖。正式版继续修改当前工作区；需要查看参考版时解压源码包到其他目录，或使用独立 Git worktree。新决策更新文档，必要时发布新参考标签，保留本版。
