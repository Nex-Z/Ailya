读取项目根目录 docs/prototype-freeze-v1.0.0.md 和 docs/production-contract.md。参考标签 prototype-v1.0.0 固定不动；需要运行参考源码时放到独立目录，不覆盖开发工作区。截图是辅助，交互以冻结源码和后续用户明确决定为准。

聚焦改动组件，沿用 Tailwind、shadcn 和 assistant-ui，保持中性色、菜单位置及窄屏布局；不新增用户未要求的说明文案。

按所改路径检查真实场景：运行时文字与工具折叠、结束总耗时、错误/重试、子 Agent 只读面板；问题每次一个、ABC 选项、推荐紧邻文字且不自动选中、共用截止时间；文件两条折叠、全路径和红绿差异。

不要仅截图验收按钮存在；点击完成相关流程，并检查切换会话、状态更新、键盘操作和窄屏无溢出。已有 Playwright 测试先复用，新增测试覆盖行为缺口，不为 CSS 类名写测试。

正式验收同时要求真实数据来源；示例、mock、模拟工具只能证明视觉/交互。报告偏差并区分缺陷与已获用户授权的改动。
