读项目根目录 docs/quality/README.md。先记录目标、范围、基线和验收，再调用相关领域 Skill 完成实现。

实现后按 ailya-review 的只读审查要求检查，再按 ailya-test 选择验证。问题修复后只重跑受影响证据。默认同一问题最多 3 轮，连续两轮没有新证据就停下诊断，不能反复猜改或降低标准。

输出具体可复核结果、证据和剩余问题，人工状态未收到回复就保持 pending。既有授权继续有效，不能用此 Skill 要求用户逐步批准普通修改。

有长期价值的新事实交给 ailya-learn 形成候选；无新事实不写经验。该流程不授权自动发布、创建子 Agent、修改冻结标签或自改质量门槛。
