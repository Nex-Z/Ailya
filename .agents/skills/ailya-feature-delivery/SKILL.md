name: ailya-feature-delivery
description: 将 Ailya 原型能力接入真实 Core、模型或工具，完成持久化、事件和前端端到端交付时使用。
---

读取项目根目录 AGENTS.md、docs/production-contract.md 和所改功能的现有组件。列出现有模拟入口及对应生产事件，保留冻结版 UI。

以功能为单位贯通 SQLite repository、Core API/执行、事件映射、assistant-ui 和真实验收。API schema、任务 ID、事件序号、错误状态有一致来源。重连通过持久化事件/快照恢复，不重新执行外部写操作。

涉及任务时区分会话、任务、重试 attempt、工具调用和问题批次 ID；新任务新计时，同一任务继续保留开始时间。问题批次截止时间持久化，超时/拒答取消执行；拒答恢复普通输入框，超时保留问题并允许提交后继续。

停止向子任务传播；已提交写操作不回滚。重试清理可见旧结果但保留必要执行审计，不能因覆盖消息重复有副作用的调用。不可取消或结果不确定的操作明确记录，不虚报完成。

验证一次成功流程及本次改动涉及的失败、停止、重连或重启边界。测试 mock 可验证界面，但交付真实工具能力还需真实执行证据。未接入的能力明确标记在交付说明，不把定时器或静态 JSON 当生产实现。

接入首个 Core 会话时同步建立 docs/quality/session-replay.md 定义的最小 Session 执行重放。后续非平凡模型可见/执行行为变化补相关场景，真实请求与结果有可追溯记录；不等所有功能完成后再补运行器。
